# homebrew-deepwiki-cli

Homebrew tap for [deepwiki-cli](https://github.com/hamsurang/deepwiki-cli) — a CLI to query GitHub repo wikis via DeepWiki.

## Install

```sh
brew tap hamsurang/deepwiki-cli
brew install deepwiki-cli
```

## Usage

```sh
deepwiki ask hamsurang/deepwiki-cli "How does the CLI work?"
deepwiki wiki hamsurang/deepwiki-cli
```

## Updating

```sh
brew update && brew upgrade deepwiki-cli
```
